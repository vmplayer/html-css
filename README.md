### Projeto Android

O Projeto Android foi um site desenvolvido ao longo [Módulo 2](https://youtube.com/playlist?list=PLHz_AreHm4dlUpEXkY1AyVLQGcpSgVF8s&si=Zv4_E9iIfHeQQEit) do curso, onde explica a forma como o mascote do Android, o Bugdroid. 

O desafio foi importante para o curso pois apresentou conceitos da responsividade, conceito de links, e alguns conceitos de determinados itens do CSS3 - Por exemplo: edição de iframes prontos por edição de uma \<div>.

### Projeto Cordel

O Projeto Cordel foi outro site desenvolvido ao longo do curso, agora no [Módulo 3](https://youtube.com/playlist?list=PLHz_AreHm4dmcAviDwiGgHbeEJToxbOpZ&si=bc3N2edDcATIiqXh).

O site conta um cordel criado por [Milton Duarte](https://www.recantodasletras.com.br/poesias/3186743), entitulado por "Cordel Moderno", projeto este que foi importante por mostrar funcionamentos específicos de caixas, posições, parallax, imagens, e colocar técnicas compostas entre HTML e CSS à prova.

### Projeto Social

O Projeto Social foi um projeto realizado ao decorrer do [Módulo 4](https://youtube.com/playlist?list=PLHz_AreHm4dkcVCk2Bn_fdVQ81Fkrh6WT&si=XCh5SsE-NC_XAF8P) do curso.

O projeto serve para divulgar redes sociais por meio do uso de um iframe, que simula a tela de um celular, enquanto usa uma captura de tela inteira para divulgar uma preview do perfil. Foi importante pois abordou desde a segurança, até mesmo similaridades compostas por um iframe.
